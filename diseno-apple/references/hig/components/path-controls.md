# Path controls — HIG (condensado)

- URL: https://developer.apple.com/design/human-interface-guidelines/path-controls
- Descargado: 2026-10-15
- Sección: components › Navigation and search
- Plataformas: macos
- Última actualización: sin registro de cambios

> Resumen de Apple: A path control shows the file system path of a selected file or folder.

_Formato: las frases en **negrita** son las reglas literales de Apple (citas cortas);
«…» son frases literales con valores numéricos; las tablas son las especificaciones
originales. Para el texto completo, abre la URL._
- For example, choosing View > Show Path Bar in the Finder displays a path bar at the bottom of the window.
- There are two styles of path control.
- **Standard.**
- **Pop up.**

### Best practices

- **Use a path control in the window body, not the window frame.**

### Platform considerations

- *Not supported in iOS, iPadOS, tvOS, visionOS, or watchOS.*
