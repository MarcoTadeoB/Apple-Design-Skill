# Steppers — HIG (condensado)

- URL: https://developer.apple.com/design/human-interface-guidelines/steppers

- Plataformas: ios,ipados,macos,visionos

> Resumen de Apple: A stepper is a two-segment control that people use to increase or decrease an incremental value.

_Formato: las frases en **negrita** son las reglas literales de Apple (citas cortas);
«…» son frases literales con valores numéricos; las tablas son las especificaciones
originales. Para el texto completo, abre la URL._
- A stepper sits next to a field that displays its current value, because the stepper itself doesn’t display a value.

### Best practices

- **Make the value that a stepper affects obvious.**
- **Consider pairing a stepper with a text field when large value changes are likely.**

### Platform considerations

- *No additional considerations for iOS, iPadOS, or visionOS.

#### macOS

- **For large value ranges, consider supporting Shift-click to change the value quickly.**
