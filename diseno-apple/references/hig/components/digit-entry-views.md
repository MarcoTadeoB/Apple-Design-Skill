# Digit entry views — HIG (condensado)

- URL: https://developer.apple.com/design/human-interface-guidelines/digit-entry-views
- Descargado: 2026-10-15
- Sección: components › Selection and input
- Plataformas: tvos

> Resumen de Apple: A digit entry view fills the entire screen and prompts people to enter a series of digits, like a PIN, using a digit-specific keyboard.

_Formato: las frases en **negrita** son las reglas literales de Apple (citas cortas);
«…» son frases literales con valores numéricos; las tablas son las especificaciones
originales. Para el texto completo, abre la URL._
- You can add an optional title and prompt above the line of digits.

### Best practices

- **Use secure digit fields.**
- **Clearly state the purpose of the digit entry view.**

### Platform considerations

- *Not supported in iOS, iPadOS, macOS, visionOS, or watchOS.*
